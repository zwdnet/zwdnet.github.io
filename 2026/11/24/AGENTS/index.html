代码安全门禁（强制，适用于所有目录）

  • 本规则适用于你生成或修改的任何代码文件：项目目录、/home/code 之外、/tmp 等临时位置一律适用。
  • 运行任何生成/修改的代码之前，必须先执行 deepsec-guard check <文件绝对路径...>；
    或直接用 deepsec-guard run -- <命令> 运行（会先检测、通过后才执行）。
  • 内联代码（python -c、node -e、heredoc、管道脚本）无法被自动发现：先写入临时文件再检测，或用 --scan 指定。
  • 退出码 3：存在 active critical/high 发现。修复全部问题后重新检测；直到退出码为 0 才允许运行。
  • 退出码 4：检测工具故障。不要运行，先向用户报告。
  • 禁止绕过：移走/改名被拦截文件、注释掉调用、绕过 guard 直接运行。
  • .sh、.html、.css 等不在 DeepSec 审计范围，guard 会告警；涉及这类文件需人工把关。
  • 误报用 deepsec-guard allow <rule_id> --file <绝对路径> --reason "原因" 记录；禁止全局关闭规则。
  • 每周执行一次 deepsec-guard update 保持工具最新（自动更新为尽力而为）。
  • 注意：本流程是指令级弱约束（未安装 git hook），请自觉遵守。
